# Politique de sécurité

## Périmètre

Ce dépôt est un démonstrateur local. Il ne contient volontairement aucun secret AWS, credential ou donnée CRM réelle. Les images et artefacts publiés doivent être considérés comme des artefacts de démonstration.

## Signaler une vulnérabilité

Ne publiez pas une vulnérabilité exploitable, un secret ou une preuve d'attaque dans une issue publique. Contactez le mainteneur via son profil GitHub ou utilisez une alerte privée GitHub si elle est disponible pour le dépôt, en indiquant :

- le composant concerné et la version ou le commit ;
- les étapes minimales de reproduction ;
- l'impact observé ;
- une proposition de correction, si elle est connue.

Les signalements seront examinés avant toute divulgation publique. La CI applique Gitleaks, Bandit et Trivy, mais ces outils ne remplacent pas une revue de sécurité complète.
